Generate System Reports

View and monitor reports about the activities of the rental management system.

Report Selection

Available Reports

Users Report
Displays registered tenants, house owners, and account statuses.
House Listings Report
Displays submitted houses, approved listings, pending listings, and rejected listings.
Rental Requests Report
Displays rental requests submitted by tenants and their current statuses.
Payments Report
Displays payment records and payment totals.
Complaints Report
Displays complaints and reported houses submitted by users.

System Activity Summary

Activity Description
User Registration New users registered in the system.
House Listings New properties submitted by house owners.
Listing Verification House listings approved or rejected by administrators.
User Complaints Complaints and reports submitted by users.
Account Management User accounts suspended or reactivated.

Report Management Guidelines

  1. Select the report category you want to review.
  2. Choose the required date range.
  3. Generate the report.
  4. Review the report information carefully.
  5. Use the information to monitor system activities.
